# نظام توثيق الأداء — النسخة الجديدة (بدون React / بدون Build)

هذا المشروع مبني بنفس أسلوب نظام المقاصف: ملفات HTML/CSS/JS عادية بدون أي خطوة بناء،
عشان تتجنبي كل مشاكل GitHub Actions ومسارات vite اللي واجهناها بالنسخة السابقة.

## الملفات
- `index.html` — تسجيل الدخول
- `unit.html` — الصفحة الرئيسية لموظفة/مسؤولة الوحدة (شبكة الأيقونات + قسم "البيانات الأساسية" الشغّال بالكامل)
- `style.css` — التنسيق العام
- `config.js` — دوال الاتصال بالخادم + الجلسة
- `Code.gs` — الخادم الخلفي (Google Apps Script) المرتبط بـ Google Sheet

## خطوات الإعداد

### ١) جدول البيانات
1. أنشئي Google Sheet جديد وفارغ.
2. من القائمة: **الإضافات ← Apps Script**.
3. احذفي أي كود موجود، والصقي محتوى `Code.gs` كامل.
4. من الأعلى اختاري الدالة `setup` ثم اضغطي **Run** (تشغيل) — هذا ينشئ ورقتي
   "المستخدمون" و"البيانات الأساسية" تلقائيًا، مع مستخدم تجريبي:
   - اسم المستخدم: `unit1`
   - كلمة السر: `1234`
5. **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
6. انسخي رابط الـ Web App الناتج.

### ٢) الموقع
1. افتحي `config.js` وضعي الرابط اللي نسختيه بدل `PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE`.
2. ارفعي كل الملفات (`index.html`, `unit.html`, `style.css`, `config.js`) لمستودع GitHub جديد.
3. Settings ← Pages ← Source = **Deploy from a branch** ← اختاري `main` والمجلد `/ (root)`.
   (ما فيه حاجة لـ GitHub Actions هالمرة، لأنه ما فيه بناء إطلاقًا — رفع مباشر.)
4. افتحي رابط الموقع وجربي الدخول بالمستخدم التجريبي.

### ٣) تعديل بيانات المستخدمين الحقيقيين
عدّلي/أضيفي صفوف في ورقة "المستخدمون" مباشرة (اسم المستخدم، كلمة السر، الاسم، الدور:
وحدة/قسم/إدارة، القسم، الوحدة، المسمى الوظيفي، اسم الرئيسة المباشرة).

## ملاحظات مهمة
- القسم الوحيد الشغّال حاليًا هو **"البيانات الأساسية"** — بقية الـ١٤ قسم تظهر
  بعلامة "قريبًا" بشبكة الأيقونات، وبنكملها وحده وحده بنفس الأسلوب.
- قائمة "الوحدة" تتغير حسب "القسم" المختار — القائمة الحالية بالكود (`UNITS_BY_DEPT`
  داخل `unit.html`) قائمة مبدئية، عدّليها أو قوليلي أعدّلها حسب هيكلتكم الفعلية.
- منطق إظهار حقول "تحديد الفترة" (الشهر/الفصل/تاريخ البداية والنهاية) حسب نوع الفترة
  هو افتراض أولي مني بناءً على المستند، لو تبين ترتيب مختلف قوليلي أعدّله.
- صفحتا `department.html` (القسم) و`education.html` (إدارة التعليم) للمراجعة والاعتماد
  لسا ما بنيتهم — نبنيهم بعد ما تراجعين هالنسخة الأولى.
