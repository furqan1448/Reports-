# نظام توثيق الأداء — جمعية فرقان

نظام React لتوثيق التقارير الدورية للأداء، خاص بجمعية فرقان لتحفيظ القرآن الكريم بالطائف.

## التشغيل محليًا

```bash
npm install
npm run dev
```

بعدها افتحي الرابط اللي يظهر بالطرفية (عادة `http://localhost:5173`).

## رفع المشروع على GitHub

1. أنشئي مستودع جديد على GitHub باسم **Furqan-Reports** بالضبط (نفس الاسم مهم لأن إعداد Vite مربوط فيه).
2. ارفعي كل ملفات هذا المجلد للمستودع:

```bash
git init
git add .
git commit -m "النسخة الأولى من نظام توثيق الأداء"
git branch -M main
git remote add origin https://github.com/<اسم-حسابك>/Furqan-Reports.git
git push -u origin main
```

## تفعيل GitHub Pages (خطوة تسوّى مرة وحدة بس)

1. روحي لصفحة المستودع على GitHub → **Settings** → **Pages**.
2. تحت **Build and deployment** → **Source**، اختاري **GitHub Actions** (مو "Deploy from a branch").
3. كذا خلاص — أي مرة تدفعين (`push`) على فرع `main`، الموقع يتبنى وينشر تلقائيًا عن طريق ملف `.github/workflows/deploy.yml` الموجود بالمشروع.

بعد أول نشر ناجح، الموقع يكون متاح على:

```
https://<اسم-حسابك>.github.io/Furqan-Reports/
```

## النشر اليدوي (بديل اختياري)

إذا ما بتستخدمين GitHub Actions ولك سبب معيّن، فيه طريقة يدوية جاهزة عن طريق حزمة `gh-pages`:

```bash
npm run build
npm run deploy
```

هذي الطريقة تبني المشروع وتنشره مباشرة على فرع `gh-pages`. في هالحالة، لازم تغيّرين مصدر GitHub Pages بالإعدادات إلى **Deploy from a branch** واختيار فرع `gh-pages` بدل GitHub Actions.

## بنية المشروع

```
Furqan-Reports/
├── index.html              نقطة دخول Vite
├── package.json
├── vite.config.js          يحدد base: "/Furqan-Reports/" (لازم يطابق اسم المستودع)
├── .github/workflows/
│   └── deploy.yml          نشر تلقائي على GitHub Pages
└── src/
    ├── main.jsx            يشغّل تطبيق React
    ├── App.jsx             نظام توثيق الأداء كامل (بدون أي تعديل)
    └── index.css           تنسيق أساسي بسيط
```

## ملاحظة مهمة عن حفظ البيانات

النظام يحفظ بياناته (الأقسام، الوحدات، التقارير...) في `localStorage` الخاص بالمتصفح تلقائيًا. هذا يعني:

- البيانات تُحفظ على نفس الجهاز والمتصفح اللي تستخدمينه، وتبقى محفوظة حتى لو أغلقتِ الصفحة أو أعدتِ تشغيل الجهاز.
- البيانات **لا تنتقل تلقائيًا** بين أجهزة أو متصفحات مختلفة (لأنها محلية لكل متصفح على حدة).
- لو احتجتِ مشاركة البيانات بين عدة مستخدمات أو أجهزة، هذا يحتاج ربط النظام بقاعدة بيانات حقيقية (خطوة مستقبلية منفصلة).
